# Version and updates

English · [Chinese](zh-CN/updates.md)

Open **Settings → About dant** to see the current application version. The version remains visible when the VM is disconnected.

Select **Check for updates** to query the latest public stable release of [Stephen-Sim/dant](https://github.com/Stephen-Sim/dant/releases). This check runs on Windows and does not require VM access, ChatGPT sign-in or an API key. GitHub receives an ordinary public release request; dant does not send conversation content or credentials.

The result shows whether a newer version is available. **View update** opens that version's GitHub release page, where you can choose the Windows installer or portable package. Quit dant before installing a new version.

A failed or rate-limited request shows a retry message rather than claiming the application is current. Successful checks are cached briefly to avoid repeated requests; the displayed check time belongs to that result.
