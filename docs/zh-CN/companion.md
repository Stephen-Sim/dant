# 有自己电脑的数字伙伴

[English](../companion.md) · 简体中文

dant 的定位是有宠物般陪伴感的数字伙伴：有自己的电脑、与人的持续关系、共同记忆、可辨认的性格，以及正在做的事情。你可以跟它聊天、看它的桌面、在它卡住时帮忙，也可以把任务交给它。它的判断、想法和可复用技能应来自实际经历；你交给它的任务优先于它自己的项目。

## 当前行为

聊天在消息分组之间显示时间；鼠标悬停在消息或通话气泡上，可以查看完整的本地日期和时间。

文字、订阅通话和可选 API 通话共用一份身份定义。dant 用第一人称介绍自己是数字伙伴；人类用户是另一个人。共享记忆及原有 Codex 会话保持这些入口之间的连续性。

对于每一项已接受的实际委托，包括简单发送链接或文件，共同指令要求 dant 先通过 `task_plan` 登记具体标题和步骤清单，收到保存确认后再执行。请求需要澄清时，先登记 `status: waiting_user`，至少保留一个待办步骤，不把任何步骤标为正在执行，再询问缺少的信息。文字和通话任务共用这个流程，普通聊天和单纯询问进度不建新工作条目；相关补充按真实的已保存 `workId` 接续，可跨执行轮次，不猜测最近一项任务，无关的新工作另建计划。说完一句话或汇报进度不代表完成：步骤未做完保持**进行中**，实际阻碍需要输入时显示**等待你回复**，验证完完整计划才进入待验收。登记不启动第二个执行器，也不插入用户消息。

对于待验收结果，你要求的相关修改可以沿用同一个任务。新轮次先自动记录公开计划，也不会强迫另外创建恢复任务；明确登记时可以把这份临时记录接续到原工作 ID。已验收完成的工作保持关闭。未完成计划是持续保存的任务记录，当前执行卡片则显示执行器是否实际在运行。

已经接收的工作属于任务执行器。正常挂断只结束音频，已确认任务继续执行；缩小窗口或切换界面也不会让它停止。发出进度消息或一段时间没有输出不代表任务完成。执行器的终态事件才结算回合，经过验证的结果等待你验收。“停止工作”和“挂断”是分开的操作。

挂断后，结果和问题发到原聊天里。登录凭据请求保留安全表单。正在执行的任务明确提问后，你接着发送的文字回答可以调整那个准确的任务，而不是排在它后面。未读标记和通知帮助你发现结果或问题。无法确认执行结果的操作不会被盲目重复提交。

**工作进度**从聊天顶部入口打开，待验收结果用入口上的小标记提醒。任务状态和详情显示在其面板内。文字及通话里交办的任务都会显示，包括没有用户文字气泡的语音任务。正在执行、后台继续、等待回复、正在停止、状态未确认与通话状态分开。当前任务卡展示具体标题、执行阶段、用时和最后更新时间。明确公开的步骤清单保留在当前和最近任务中；步骤计数不猜测剩余时间，也不覆盖执行器的真实任务状态。

聊天上方的简洁进度卡片由**通用 → 在聊天中显示任务进度**控制，默认关闭并保留选择；这个显示偏好不改变任务执行或通话音频。

最近任务包含文字任务和通话最终结果。点击 **×** 可从工作进度中收起未在执行的条目，保留聊天、任务状态、已读回执和模型上下文。正在执行的工作仍通过独立的**停止工作**操作结束。查看结果继续遵循聊天的实际可见未读规则。

任务提供**高、普通、低**三个显示优先级，重启和相关后续任务会保留选择。进行中和最近任务先按优先级，再按完成状态和更新时间排序；当前执行仍置顶，执行队列保留真实顺序。移除未完成条目需要单独确认。**已完成的任务 → 清空全部**会清理全部符合条件的已完成进度条目，包括当前列表未显示的记录；待验收、未完成计划、结果未确认或仍在使用的条目会保留。清理进度不会接受结果或删除聊天。

连接状态过期时，界面保留上次已知任务，并标明状态未确认。没有声音或输出不会让任务被判定完成、取消或重跑。结果未确认的文字任务仍须由你明确决定是否重新执行。

共同身份说明鼓励它主动提出有用想法、自然选择表情反馈，并创建或改进相关技能。当前版本通过消息、通话请求及已有定时任务执行工作，尚未增加一个在空闲时自行选择项目的独立生活调度器。持久的个人项目和主动空闲活动是后续产品能力，与让已经接收的任务持续执行分开实现。

## 参考 OpenClaw 的部分

OpenClaw 的[代理循环](https://docs.openclaw.ai/concepts/agent-loop)区分等待与执行：等待超时不会取消代理，原生 Codex 自己确定准确的回合完成。[后台执行](https://docs.openclaw.ai/gateway/background-process)将结果送回拥有它的原会话。dant 借鉴这些生命周期原则，继续使用原 Codex 回合，而不是挂断后再提交一遍任务。

[Heartbeat](https://docs.openclaw.ai/gateway/heartbeat) 是独立的主动检查，不负责维持当前任务。[Goal 自动继续](https://docs.openclaw.ai/tools/goal)可为未来的持久任务清单提供参考，但官方说明其自动推动不适用于原生 Codex。dant 因此不会把该接口说成已有能力，也不靠定时重复发送“继续”维持任务。
