4. 通话内显式文字通过相同线程真实执行、确认和交付；重复 clientMessageId 没有再次执行。
5. 挂断得到停止确认，保存实际连接过的通话记录。

这条链路未配置 API Key。早期只测默认 WebSocket 通道并据此判断订阅语音不可用，是错误推断；已改为默认 V3 WebRTC 订阅通道。可选 API 语音未用付费 Key 实测。
