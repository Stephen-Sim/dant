# 凭据与可复用技能

[English](../credentials-and-skills.md) · 简体中文

连接工作电脑后，打开**设置 → 凭据保险箱**，或左侧栏 dant logo 下方的**技能**拼图图标。两者由 Ubuntu Worker 持有，与其对话一起管理；不会给 Windows 宿主机或 Codex 桌面应用安装技能。

## 凭据流程

在独立密码字段中填写名称、服务或主机名、可选用户名，以及密码、Token 或 API Key。列表只显示元数据。编辑时不读取原有秘密值：密码框留空保留原值，填写则替换。移除前需要确认。

dant 需要登录时，模型工具可以查找已保存的凭据元数据，并为该登录操作读取相应值。缺少凭据时，会提出带服务与用途的请求。应用打开独立安全表单，并在聊天和设置中保留待办入口。**保存并继续**会保存凭据并恢复等待中的工具；**取消请求**则拒绝提供。不要把秘密值填写到普通聊天输入框。

VM 保险箱使用 AES-256-GCM 加密。主密钥单独保存，文件权限为普通 VM 用户专属的 `0600`；这保护磁盘文件，不隔离同一 VM 用户或管理员。此保险箱不使用 Windows DPAPI。Windows 设置、状态事件、列表及离线缓存只有凭据元数据，没有秘密值。普通界面更新会保留当前密码控件中的输入；关闭表单或保存成功后清空，不写入 localStorage，也不显示到提示消息。

`credential_get` 会在登录需要时，将秘密值明确提供给模型的限定工具上下文，不作为普通聊天回复。不得把秘密值回显到聊天、命令输出、代码仓库或技能文件。可选付费语音 API Key 仍是独立设置，见[语音配置](VOICE-KEY.md)。

## 技能流程

技能使用独立的插件式卡片页面。可搜索名称或说明、创建技能，并通过卡片操作编辑、启用、停用或移除。离线时保留已缓存卡片，重新连接工作电脑后才能修改。打开该页不会启动任务或运行技能。

创建或编辑小写名称、说明和使用正文。展开**支持文件（JSON）**后，可填写 `{"scripts/check.py":"print('check')"}` 这样的映射。路径仅限相对的 `scripts/`、`references/` 和 `assets/`。正文最多 48 KiB，说明最多 1000 个 UTF-8 字节，支持文件最多 20 个、每个 64 KiB，正文与支持文件合计最多 256 KiB。

启用技能保存在托管工作区的 `.agents/skills/<name>/SKILL.md`；停用后移到扫描目录外的 `.dant-disabled-skills/`。列表显示真实 VM 路径，可编辑、启停或移除托管技能。本页不管理无关的系统或用户技能目录。

模型可在发现可复用流程时创建技能。保存会生成真实 `SKILL.md` 和支持文件，并请求刷新技能发现；**不会执行脚本**。发现与脚本验证分别记录：已列出或刚保存不代表脚本测试通过。需要在 VM 中明确运行支持程序，并核对结果。

## API 边界

| 接口 | 用途 |
| --- | --- |
| `GET /api/credentials` | 仅列出元数据与待办请求 |
| `POST /api/credentials`、`PATCH/DELETE /api/credentials/:id` | 新增、修改或移除凭据 |
| `POST/DELETE /api/credentials/requests/:id` | 提供或取消请求中的凭据 |
| `GET /api/skills`、`GET /api/skills/:name` | 列出元数据，或读取托管正文与文本文件 |
| `POST /api/skills`、`PATCH/DELETE /api/skills/:name` | 保存、编辑、启停或移除托管技能 |

这些接口沿用本地 Controller 与 VM 的认证边界。写入已确认后，即使随后的元数据刷新失败，也不会自动重复写入。

## 验证边界

真实 VM 验收使用合成凭据完成请求、保存和读取，随后移除。真实模型创建技能、执行 Python 支持程序，并交付了已核对的标准输出；临时技能随后也已移除。真实模型还调用表情工具为测试用户消息添加表情。原有会话身份、27 条已有消息及旧状态哈希均保留。界面表单另有模拟 DOM 测试；这不代表所有真实账号、凭据类型或支持脚本都已测试。详见[验证记录](verification.md)。
