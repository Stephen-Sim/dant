# 版本与更新

[English](../updates.md) · Chinese

打开**设置 → 关于 dant**，可查看当前应用版本；VM 断开时仍能显示版本号。

点击**检查更新**，会查询 [Stephen-Sim/dant](https://github.com/Stephen-Sim/dant/releases) 最新公开正式版。检查在 Windows 上执行，无需连接 VM、登录 ChatGPT 或配置 API Key。GitHub 收到普通的公开版本查询请求，dant 不会发送聊天内容或凭据。

结果会显示是否有更新。**查看更新**打开对应版本的 GitHub Release 页面，可选择 Windows 安装包或便携包。安装新版前请先退出 dant。

请求失败或被限流时会显示重试提示，不会误报为最新版。成功结果会短暂缓存，避免重复请求；显示的检查时间对应这次结果。
