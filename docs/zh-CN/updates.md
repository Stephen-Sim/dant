# 版本与更新

[English](../updates.md) · Chinese

打开**设置 → 关于 dant**，可查看当前应用版本；VM 断开时仍能显示版本号。

先选择**正式版**或 **Beta**，再点击**检查更新**。正式版只检查已发布的正式版本；Beta 也包含已发布的测试版，并选择版本号最新的一版。渠道选择保存在本机；切换渠道不会自动安装或降级。

检查在 Windows 上查询 [Stephen-Sim/dant](https://github.com/Stephen-Sim/dant/releases) 的公开版本，无需连接 VM、登录 ChatGPT 或配置 API Key。GitHub 收到普通的版本查询请求，dant 不会发送聊天内容或凭据。检查只在你发起时执行，两个渠道分别短暂缓存结果。

Windows 可点击**下载更新**，在后台下载官方安装包并核对大小与 SHA-256，期间聊天、通话和任务继续运行。校验完成后，默认每用户安装位置 `%LOCALAPPDATA%\dant` 可点击**安装并重启**；便携版和自定义目录通过发布页手动安装。安装前先确认工作已暂停，结束当前通话并交还已知的人工控制权，再挂起受管理的整台 VM；任务、执行结果或控制权未确认时，不继续安装。安装器更新本地应用，重新打开后恢复原 VM 并检查配套服务。普通 SSH 电脑可以暂停工作，但缺少可验证的虚拟机管理身份时无法挂起整台 VM。录音、听写、未发送的音频和正在提交的输入需要先处理。安装失败会显示简短恢复提示，不会自动启动可能只更新了一部分的应用。

更新重启前，dant 会暂存当前未发送的聊天文字、引用回复和已上传的附件引用。草稿限制大小与保存时间，只在同一工作电脑、同一聊天中恢复。录音草稿需要先发送或丢弃；安全输入的内容不会写入这份草稿。

**查看更新**打开对应发布页，可查看说明或手动下载安装包、便携包。手动安装仍需先从托盘退出 dant。如果安装包无法校验，或当前应用目录不支持自动安装，可使用发布页手动更新。

请求失败或被限流时会显示重试提示，不会误报为最新版。失败或未完成的下载不能安装。

## 工作电脑服务更新

dant 会在安装后或启动连接时，检查随桌面应用提供的工作电脑服务。工作电脑忙碌时，先连接原服务并保留待更新状态；新的实际状态确认任务、通话和电脑控制均空闲后，自动继续更新，无需另点 Reconnect。短暂连接失败采用有上限的间隔重试；普通网络恢复不会反复部署已经更新的服务。

**设置 → 工作电脑**显示更新状态，以及目标版本／已确认的运行版本。缓存连接或安装脚本成功退出，均不足以代表服务已更新；程序通过当前 VM 连接确认实际版本。自动更新不会唤醒因安全原因明确停止的执行器。更新结果未确认时，先只读核对，不重放暂停或重启操作；**暂停更新**会暂停自动服务更新，直到点击**恢复更新**。点击**暂停任务并安装**或明确点击 **Reconnect**，会先暂停工作并确认保存的任务记录，再替换服务。通话或控制权变化、执行结果未知时，不进行替换。已暂停任务需要明确回复该任务或点击继续后恢复。

配套服务要求 Node.js 22.18+ LTS 或 24+，并支持原生 TypeScript、内置 SQLite 和 FTS5。预检、打包和 VM 部署会用有时间上限的内存数据库查询验证这些能力。如果 Reconnect 报告 `runtime-incompatible`，dant 会保留现有 VM 运行时与服务。请通过该 VM 的维护流程更新 Node 运行时，然后重新连接。

**0.4.7-beta.8** 会先备份旧记忆和调度，再单次导入 Worker 数据目录下的 `memory/dant/memory.sqlite` 与 `schedules/schedules.sqlite`。聊天消息与持久任务仍由 `state.json` 保存。备份数据时保留这些数据库；切换应用版本不会逆转数据迁移。恢复的调度派发保留准确消息身份，保持暂停或不确定状态，不会再次发送。

## 0.4.7-beta.5 的工作电脑更新

桌面安装器会保留正在运行的 VM 服务。在 **0.4.7-beta.5** 中，明确点击**设置 → 工作电脑 → 刷新连接（Reconnect）**时，如果打包源码有变化，也会更新该服务。程序先准备依赖，再让现有服务确认暂停全部工作、保存任务记录并结束当前通话，然后替换服务。它使用旧版已有的全局暂停接口，无须先具备新版的单任务 Pause 接口。已暂停工作仍可明确继续。

在该版本中，打开应用或网络自动重连时，会保留繁忙中的工作；已部署源码相同时，刷新连接也不会打断任务。暂停、控制权或执行结果未确认时，不会替换服务。新版启动失败时，只有确认没有新工作开始，才恢复旧运行环境；聊天、记忆、技能和任务记录不会回滚。单任务暂停／继续接口缺失时显示更新提示，不会静默暂停其他任务。

## 退出与恢复

关闭窗口仍保留在托盘；明确选择**退出**时，先确认工作暂停，再挂起受管理的整台 VM。重新打开时验证身份并恢复原 VM。如果恢复被拒绝或未能确认，可通过 **Reconnect** 重新尝试经过身份核对的恢复，不会选择其他 VM。普通 SSH 连接会明确提示无法挂起整台 VM。
