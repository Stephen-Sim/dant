# 版本与更新

[English](../updates.md) · Chinese

打开**设置 → 关于 dant**查看已安装版本，VM 断开时也可查看。选择**正式版**或 **Beta**，再点击**检查更新**。正式版只检查已发布正式版，Beta 也包含已发布预览版并选择最新版本；保存渠道不会自行安装或降级。

Windows 更新检查查询公开的 [Stephen-Sim/dant releases](https://github.com/Stephen-Sim/dant/releases)，不需要 VM、模型账号或 API Key，不发送聊天或凭据。检查仅在发起时执行，各渠道分别短暂缓存；失败或限流会提示，不误报当前已是最新版本。

## 桌面应用

**下载更新**在后台下载官方 Windows 安装包并校验大小及 SHA-256，期间聊天、通话和工作可以继续。失败或未完成的下载不能安装。

默认每用户安装位置的**安装并重启**使用原生保护更新流程。安装前确认工作暂停、结束当前通话、归还已知人工控制并挂起所属托管 VM；执行或控制结果未知时阻止安装。先处理录音、听写、安全输入和正在提交的输入。普通 SSH 连接可以暂停工作，但缺少已验证管理身份时不能宣称整台 VM 已挂起。

重启草稿只在同一工作电脑、同一对话内保留有界的未发送文字、引用回复和已上传附件引用；不包含安全输入，音频草稿须先发送或丢弃。安装失败显示恢复提示，不会自动启动可能只安装了一部分的应用。

便携版和自定义目录通过发布页手动安装。先从托盘选择**退出**，确认原生和 Controller 进程停止；不能用静默安装器强行关闭应用。**查看更新**打开准确的已发布版本，用于阅读说明或手动下载。

## 工作电脑服务

Controller 在安装后或启动连接时检查打包 Go Worker 的源码。忙碌工作继续连接现有服务，更新保持等待；新的实际状态确认任务、通话和控制均空闲后再更新。连接重试有界，普通网络恢复不会反复部署已是当前的源码。

**设置 → 工作电脑**显示目标版本与已确认运行版本。缓存状态和脚本成功不足以证明实际运行源码。**暂停更新**阻止自动服务更新，直到点击**恢复更新**。明确选择**暂停任务并安装**或 **Reconnect**，先暂停工作、核对已保存任务并确认执行停止；已暂停工作需要匹配回复或明确继续才能恢复。

现有维护协议在替换期间阻止新准入。已确认安全停止的执行器可以使用受支持的空闲恢复见证，不继续暂停工作。缺少单任务能力时显示服务更新提示，不静默暂停无关工作。更新结果未知时必须先核对，不能删除回执来绕过保护。

部署校验 Linux 程序、固定辅助文件、版本、源码和哈希。停服务前按各文件系统检查捕获、归档和准备空间；离线准备数据前要求完整认证私有备份及执行器停止证明。新 Worker 必须证明角色、Go 运行时、协议、目标版本及源码，才标记部署完成。失败保留数据、日志、备份和不确定状态。

持久安装日志同时保护独立服务启动和重启；只有匹配的成功准备证明允许激活。准备前中断且符合条件的尝试具备显式身份绑定恢复入口，自动检查不修改日志或重放安装。参见 [Go Core](go-core.md)、[运行支持](runtime-support.md)和[备份](backups.md)。

## 保存数据与附件

聊天和持久工作在 `state.json` 中保留身份；记忆和调度使用 Worker 数据目录中的 SQLite 数据库。受支持的早期 JSON／Markdown 格式在单次导入前先校验和备份。过期文件不能替换更新的权威数据库，也不能恢复已删除调度；应用版本变化不逆转数据准备。

恢复后的附件在模型输入或转录前，通过稳定 ID 从当前存储校验并解析，支持不同 home／工作区根目录，不复用历史文件路径。缺失、变化或未确认文件阻止执行。恢复保留未知提交，暂停未完成工作和调度。

## 恢复设置与退出

聊天状态无法加载时，恢复设置独立读取本机连接配置并显示 Controller 版本，允许检查 SSH 设置、选择发现的配置，并在 VM 离线时检查已发布更新。保存设置不会连接或部署。原电脑无法完成所需的更换前备份时，可明确同意仅本次改变连接；这不会关闭未来备份，也不能绕过未知恢复保护。

关闭窗口后 dant 保留在托盘。明确**退出**先确认工作暂停，再挂起所属托管 VM。重新打开恢复同一经验证 VM；**Reconnect** 可在所有权检查后显式恢复未记录的 Saved 状态，不选择其他 VM，也不通过这条恢复路径自动启动 Off VM。替换服务时 VM 保持开机。

源码检查、候选产物和真实安装验收彼此独立，参见[测试](testing.md)、[CI](ci.md)和[验收](verification.md)。
