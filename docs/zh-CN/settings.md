# 设置

[English](../settings.md) · 简体中文

设置按菜单分类：通用、外观、语音、工作电脑、ChatGPT、凭据、聊天与数据、Telegram、关于。窗口较窄时使用紧凑菜单。

通过**搜索设置**，可跨分类查找具体设置项。不论界面语言，都可使用中英文名称或关键词。选择结果后，会打开对应分类并聚焦具体控件，包括高级选项中的控件。

搜索使用固定的设置名称和帮助关键词目录，不检索聊天历史、凭据值或账号详情。聊天记录搜索是聊天页面中的独立操作。

**聊天与数据 → 记忆与人格**显示 dant 实际使用的共享身份，以及工作电脑上的持久参考记忆。文字和两种语音通道共用这些参考内容，凭据值会被隐藏。此处只读，可手动刷新；工作电脑离线时会标明已加载内容是上次读取的副本。定时任务保留在侧栏中。

切换分类会保留本地表单草稿和正在进行的通话。部分设置需要连接工作电脑；外观、应用版本及更新检查在本机处理，详见[版本与更新](updates.md)。

## 聊天和通话操作

聊天在对话开头、跨日或间隔超过 30 分钟时显示时间分隔线。每条消息的原发送时间仍会保存，编辑消息也不会改变它。dant 已完成回复会显示**已读**或**未读**。侧栏角标统计未读回复，点击**未读消息**按钮可跳到第一条。

你发送的消息保存后显示单勾，执行器确认收到后显示双勾；这不代表模型已经理解，也不代表任务完成。当前任务能接收补充时，新聊天消息会直接送给它，否则留在队列中。明确恢复的任务及计划任务仍独立排队。订阅通话留下的后台任务可接收文字补充，附件则等待单独执行。

通话接通后，输入文字会交给同一通话，由 dant 用语音回应。引用回复包含原消息和说话者，两种语音通道共享同一会话记忆。通过顶部按钮查看工作进度；任务步骤列表的展开状态会在刷新或重新打开面板后保留。

已确认的任务运行时也可以开始通话，包括上一通话挂断后继续执行的工作。原任务及安全输入请求保留身份和进度；连接失败或正常挂断不会暂停它。通话或执行归属尚未确认时，仍需先确认状态才能再次连接。

打开、关闭或调整 Computer 面板时，聊天会保持在当前正在看的消息附近。原本贴底时继续贴底，阅读旧消息时不会强制跳到最新一条；图片延迟加载也会保留当前视图。搜索、未读消息和任务结果的跳转仍会定位到选中的消息。

在工作进度中点击 **×** 或**取消当前工作**，确认后取消选中的工作。确认停止后，任务移到最近的任务中显示为**已取消**，保留步骤、结果和文件；停止未确认时仍保持可见。其他排队任务和当前通话会保留。已取消任务不会自动恢复，也不计入“清空已完成”。也可以让 dant 通过 `task_list` 查找任务，再用 `task_cancel` 自行取消指定任务。

在**通用 → 在聊天中显示任务进度**中，可开启聊天上方的简洁进度卡片。默认关闭，重启后保留选择；点击卡片打开同一个工作进度面板。开关只控制显示，不会启动、暂停、完成任务或改变当前通话，顶部按钮始终保留。

须在聚焦的前台文字聊天中，让实际气泡在视口内可见并持续 450 毫秒，才会标记已读。最小化应用、显示完整通话视图、切换页面或打开弹窗会停止此跟踪。恢复窗口或收到通知不会把未看到的回复标为已读。回执保存在 VM 对话中，本机通知送达另行记录。

在“通用”中启用**消息通知**，可接收未读结果或需要补充信息的提醒。通知表示 dant 有消息给你，不一定代表任务已完成。本机提醒需要 Windows 应用保持运行，并已获得通知权限。

点击**缩小到聊天**会显示头像在左侧的可拖动横向通话条。通话中最小化 Windows 应用或关闭主窗口到系统托盘，会在屏幕右下方、任务栏上方显示独立桌面条。拖动其背景可移动位置，展开按钮恢复主窗口；恢复主窗口或结束通话后隐藏。两种通话条共用原通话、麦克风与计时，不额外建立音频会话。浏览器模式使用应用内通话条。

桌面条的**隐藏通话窗口**按钮可在本次通话中隐藏它，音频和已接受的工作继续进行。状态刷新不会让它重新弹出，开始新通话后重置这一选择。

确认接通后可点击**接管电脑**，音频保持连接。只有准确的当前任务已确认停止、VM 确认人工租约后才开放输入，排队任务同时暂停。**交还 dant** 不会重跑任务，需要继续时可在原通话中重新交代。连接中、停止中或状态未确认时仍禁止开始接管；已有人工租约仍可交还。

附件下载按钮会保留聊天和图片预览。桌面“另存为”默认使用原文件名与扩展名，浏览器模式发起文件下载；取消后保留当前视图。

同条消息内的附件使用统一间距，紧凑文件卡片把文件名、**查看**和下载按钮放在同一边框内。长文件名保持单行，悬停可查看全名，下方显示类型和大小。图片加载期间会预留空间，失败时显示稳定的错误提示；这项调整改善显示，不改变传输速度。

文本和代码附件提供**查看**及独立下载按钮。点击聊天或对话详情中的文件名，可打开能关闭的纯文本预览。JSON 格式化会保留原始数字值；嵌套过深或格式化后过大时，显示完整原始文本。预览支持最大 1 MiB 的 UTF-8 文本，较大文件仍可下载或使用桌面编辑器打开。HTML、SVG 只显示源码，不执行链接、标记或脚本。

在**通用 → 文本编辑器**中，可保留 Windows 记事本，或选择已安装且受支持的编辑器程序，例如 VS Code、Notepad++、Sublime Text、Zed 或 Cursor。**在编辑器中打开**会打开最大 10 MiB 文本附件的本地副本，不更改聊天附件。应用直接启动指定编辑器，不使用可能执行脚本的文件关联。未改动的缓存副本三天后过期，之前打开并编辑过的副本会保留。

可复用技能使用独立侧栏页面，可通过**导入技能**预览来源，也可点击托管卡片的**下载 ZIP**。详见[凭据与技能](credentials-and-skills.md)。

## Windows 后台运行

点击主窗口的 **X** 会把 dant 收到 Windows 系统托盘。应用、通话和已接受的任务继续运行，关闭窗口不会暂停或取消工作。点击托盘图标或选择**打开 dant** 可恢复原窗口，再次启动 dant 也会恢复已有实例。

托盘显示简短的在线、工作或等待状态及排队数量，点击**任务进度**可直接打开任务面板。托盘文字不包含消息、任务标题、文件名或凭据；断连或缓存中的未结束任务会显示状态待确认，不会被当成完成。

在托盘菜单选择**显示通话窗口**可恢复已隐藏的桌面通话条；没有当前通话时此操作不可用。

要结束应用，请在托盘菜单选择**退出 dant**，应用会执行正常关闭流程。手动安装更新前请使用此操作，应用内更新会自行处理重启。如果系统无法创建托盘图标，关闭主窗口仍会正常退出，避免留下无法访问的隐藏应用。托盘功能不会在 Windows 重启后自动启动 dant。

## 定时任务

左侧栏 Skills 旁的时钟入口打开**定时任务**。可以搜索、筛选即将执行、已暂停和历史条目，创建、编辑、暂停或移除任务。新建采用本机时区，编辑保留任务原有时区，显示在日期时间字段旁；每条记录显示保存的执行时间和时区。目前为单次执行，创建或编辑只保存安排，不会立即执行任务内容。

也可以在聊天或通话里直接让 dant 安排工作，共享的 `schedule_list`、`schedule_save`、`schedule_delete` 工具管理同一批记录。dant 需要采用正确时区，并在保存确认后才能声称安排成功。工作电脑不可用、正在通话或被人工接管时，到期任务等待执行通道恢复；关闭窗口收到托盘会保留服务。
