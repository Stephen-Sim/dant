# 设置

[English](../settings.md) · Chinese

设置按菜单分类：通用、外观、语音、工作电脑、ChatGPT、用量统计、凭据、聊天与数据、Telegram、关于。窗口较窄时使用紧凑菜单。

**通用 → 语言**使用支持键盘操作的下拉框，提供 English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Русский、العربية、हिन्दी、Bahasa Indonesia、Bahasa Melayu、Italiano、Türkçe 共 16 种界面语言。日期和数字采用所选地区格式，阿拉伯语从右向左排版。语言偏好保存在本机，并同步给兼容的工作电脑；切换语言不会翻译聊天历史、任务标题、文件或记忆。本地语音需要 Windows 已安装匹配的声音或识别器。

欢迎页和未连接的 Computer 面板中的**连接我的电脑**会直接打开**设置 → 工作电脑**，并定位到连接卡片。已有的设置搜索会清空，连接表单草稿会保留；打开分类不会保存配置或发起连接。

通过**搜索设置**，可跨分类查找具体设置项。不论界面语言，都可使用中英文名称或关键词。选择结果后，会打开对应分类并聚焦具体控件，包括高级选项中的控件。

搜索使用固定的设置名称和帮助关键词目录，不检索聊天历史、凭据值或账号详情。聊天记录搜索是聊天页面中的独立操作。

**通用 → 消息通知**统一控制桌面通知及其 Windows 系统提示音。未读结果或需要你回答的消息会短暂等待后再提醒；流式文字和安静的自动任务检查不会额外触发通知。在等待期间读过消息，就不会提醒。Windows 的通知权限、声音设置和**免打扰**仍然生效；dant 不会另播音频绕过系统设置。

**聊天与数据 → 记忆与人格**管理工作电脑上由 SQLite 保存的共享文档、事实和过往经历。搜索与分页列表保留来源和项目引用。**共享人格**单独显示固定的共享身份指令，保持只读。管理记忆需要连接兼容的工作电脑；离线副本会标明来源，不能编辑。

可以编辑共享文档或清空正文，编辑或删除结构化记录，并在审核后明确确认候选记忆。编辑事实会将其返回候选状态。敏感值会隐藏，经过脱敏的记录禁止覆盖编辑，避免丢失隐藏的原文。写入会核对数据库修订；状态过期或结果未确认时，须重新读取再操作。刷新不会生成记忆或启动任务。聊天与通话历史另行保留，目前没有自动整理记忆的流程。详见[上下文中的持久记忆与人格说明](context.md#持久记忆与人格)。

切换分类会保留本地表单草稿和正在进行的通话。部分设置需要连接工作电脑；外观、应用版本及更新检查在本机处理，详见[版本与更新](updates.md)。

**聊天与数据**也包含备份模式、间隔、已保存副本和便携导出。**工作电脑 → 导入备份文件**方便设置电脑时导入已有的 dant。导出选择一份已保存副本，VM 离线时也能操作；没有副本时须先创建备份。详见[备份说明](backups.md)。

已准入请求即将发送时，dant 会在对应对话/任务范围召回相关的确认事实，排除其他项目、候选和冲突条目。召回不修改你的消息或创建另一项任务，刷新记忆页面也不会触发召回或整理。详见[记忆架构](architecture.md#memory存储缓存与召回)。

## Token 用量

**设置 → 用量统计**显示 dant 收到的服务方实际输入、缓存输入、输出、推理输出及总 Token。ChatGPT 工作与可选 API 语音分开统计，可查看已记录总量和最近一次模型响应。缓存输入已计入输入，推理输出已计入输出；未提供的字段显示“暂无数据”，不会当成零。这些数字不代表账号剩余额度或账单。

用量回执保存在工作电脑，重连和重启时去重。ChatGPT 数字来自 Codex 线程的累计用量，API 语音来自已完成响应的回执；没有用量回执的原生语音音频不作估算。未保存回执的旧 API 通话无法还原，离线统计会标明是保存的数据。

**0.4.7** 提供 **Token 活跃度**图表，可切换**每日**、**每周**和**累计**视图，并显示累计 Token、单日最高用量及连续活跃天数。ChatGPT 工作与 API 语音可分别查看；悬停或用键盘选中日期、周或数据点，即可看到日期和准确用量。输入、缓存与输出明细保留在图表下方。

图表使用最近 365 天有日期的回执，工作电脑最多保留 400 个日历日。日历沿用首次创建每日历史时的设置时区，并在图表旁显示；之后更改设置时区不会把旧回执移到其他日期。没有报告的日期代表用量未知。旧的 ChatGPT 累计总量仍计入累计 Token，不会全部算在今天；只有可核对的最近一次响应和之后新增的用量才会形成每日记录。已保存的旧 API 回执沿用原时间。没有日期或更早的用量不计入图表及连续天数。

## 聊天和通话操作

聊天在对话开头、跨日或间隔超过 30 分钟时显示时间分隔线。每条消息保存的发送时间会持续显示在气泡下方，与状态及回执紧凑排列。编辑不会改变原发送时间；缺少有效保存时间的消息不显示时间。dant 回复停止流式生成后会显示**已读**或**未读**，包括暂停或失败后保留的部分回复。已读状态只表示你是否看过这条消息，不会完成或恢复已暂停的任务。侧栏角标统计未读回复，点击**未读消息**按钮可跳到第一条。

每条消息的 **…** 菜单都有**置顶／取消置顶**和**添加／取消星标**。有置顶消息时，聊天顶部显示紧凑摘要，点击可跳回原消息，多条置顶可切换查看。聊天顶部的 **…** 菜单提供**星标消息**、**搜索**及**媒体、文档和链接**，这些列表也能通过懒加载定位较早的原消息。置顶和星标仅保存工作电脑上的消息标记，不会发送指令、改变已读回执或重新打开任务；已接通话和执行任务期间也可操作。

需要听文字回复时，打开该消息的 **…** 菜单，选择**朗读**；播放期间，同一菜单会显示**停止朗读**。仅打开菜单不会播放。回复仍在生成或其他音频活动占用时，朗读不可用。语音附件继续使用各自的播放控件。

Windows 朗读使用本机的播放设备。没有可用输出时，请检查 Windows 声音输出并连接播放设备后再试。语音失败会按当前语言显示简短提示；本地原生语音诊断只保留有限的操作元数据，不记录朗读正文或听写内容。

你发送的消息保存后显示单勾，执行器确认收到后显示双勾；这不代表模型已经理解，也不代表任务完成。当前任务能接收补充时，新聊天消息会直接送给它，否则留在队列中。明确恢复的任务及计划任务仍独立排队。订阅通话留下的后台任务可接收文字补充，附件则等待单独执行。

通话接通后，输入文字会交给同一通话，由 dant 用语音回应。引用回复包含原消息和说话者，两种语音通道共享同一会话记忆。顶部的**工作进度**按钮在宽窗口中打开聊天与 Computer 之间的独立滚动面板，窄窗口会调整为上下排布。再次点击这个按钮或聊天上方的 **Working／正在工作**任务条会关闭面板，不会暂停任务。关闭进度面板保留 Computer、聊天草稿和滚动位置；任务步骤列表的展开状态会在刷新或重新打开面板后保留。

拖动两侧分隔线，可以调整相邻区域：聊天／工作进度，以及工作进度／Computer。宽度会在本机记住，并保留各区域的最小可用空间。聚焦分隔线后，也可以用**左／右方向键**或 **Home／End** 调整。空间不够时，Computer 会移到聊天与工作进度下方；窗口更窄时，三个区域上下排布。空间恢复后会重新使用已保存的宽度。调整宽度不会刷新聊天、中断任务或改变通话。

自动续作会在原任务中继续执行剩余工作。例行检查和中间结果保持安静，完成、失败或确实需要你回复时才发聊天消息；你主动发送的普通消息仍正常回复。执行轮次结束不代表任务已经完成。

头像下方的实时字幕显示订阅和 API 通话中收到的 dant 发言文字。**语音 → 通话字幕**与通话中的字幕按钮共用持久偏好，默认开启，切换不影响音频。字幕经过凭据脱敏，仅保留在内存中；桌面轮询读取当前通话快照。最后一段会保留到下一次回应清除或替换，或通话结束、断开为止。字幕不写入聊天、诊断或备份，也不保证提供双方完整转写。展开通话仅占聊天区域，Computer 和工作进度仍然可见。

已确认的任务运行时也可以开始通话，包括上一通话挂断后继续执行的工作。原任务及安全输入请求保留身份和进度；连接失败或正常挂断不会暂停它。通话或执行归属尚未确认时，仍需先确认状态才能再次连接。

打开、关闭或调整 Computer 面板时，聊天会保持在当前正在看的消息附近。原本贴底时继续贴底，阅读旧消息时不会强制跳到最新一条；图片延迟加载也会保留当前视图。搜索、未读消息和任务结果的跳转仍会定位到选中的消息。

在工作进度中点击 **×** 或**取消当前工作**，确认操作会显示在选中任务的卡片内，并绑定其当前身份。确认停止后，任务移到最近的任务中显示为**已取消**，保留步骤、结果和文件；停止未确认时仍保持可见。其他排队任务和当前通话会保留。已取消任务不会自动恢复，也不计入“清空已完成”。也可以让 dant 通过 `task_list` 查找任务，再用 `task_cancel` 自行取消指定任务。

**暂停**只停止选中的当前或进行中任务，保留原任务身份、步骤和部分结果，并保持**已暂停**，直到你点击**继续**。自动检查会跳过已暂停任务；继续时沿用原工作 ID，等待共享执行器可用。通话和其他排队工作保留；停止未确认或任务身份过期时，不会误报暂停成功或静默重跑。

**0.4.7** 可点击**回复任务**，直接回到文字聊天，在输入框上方选中该任务。原有草稿、文件和普通消息引用都会保留。发送后，用新回答或补充要求继续同一任务，不会重发原始请求；其他任务正在执行时，这条回复等待自己的任务。已发送消息也会保留任务引用。任务身份变化或不可用时保留草稿，提示重新选择；旧工作电脑服务需要先更新。

工作进度中，当前已登记任务与已保存任务采用相同的紧凑卡片排版：标题和状态、可折叠的步骤列表，以及卡片底部同一行的**回复任务**、优先级、**查看任务详情**和适用的暂停按钮。当前任务保留执行阶段与已用时，右上角的 **×** 取消这项指定任务。回复任务替代独立的调整输入框。已完成、已取消、失败及待验收任务不再显示优先级；发送新回复可带着已有项目上下文重新打开同一任务。仅点击回复不会开始执行。**查看任务详情**展示步骤、原始要求、你的补充、历史结果和文件引用，方便在继续前回顾项目。保存的摘录仅供参考，不代表对历史结果进行了独立验证。

**在线**表示当前连接正常；**空闲**表示没有任务正在执行；**等待你回复**表示保留的任务需要你回答。最近活跃时间可悬停查看，不代表离线时长。真正等待缺失信息或真人验证的任务不会因时间过去自动继续；完成所需步骤后，回复该任务即可继续。

在**通用 → 在聊天中显示任务进度**中，可开启聊天上方的简洁进度卡片。默认关闭，重启后保留选择；点击卡片打开同一个工作进度面板。开关只控制显示，不会启动、暂停、完成任务或改变当前通话，顶部按钮始终保留。

须在聚焦的前台文字聊天中，让实际气泡在视口内可见并持续 450 毫秒，才会标记已读。最小化应用、显示完整通话视图、切换页面或打开弹窗会停止此跟踪。恢复窗口或收到通知不会把未看到的回复标为已读。回执保存在 VM 对话中，本机通知送达另行记录。

在“通用”中启用**消息通知**，可接收未读结果或需要补充信息的提醒。通知表示 dant 有消息给你，不一定代表任务已完成。本机提醒需要 Windows 应用保持运行，并已获得通知权限。

点击**缩小到聊天**会显示头像在左侧的可拖动横向通话条。通话中最小化 Windows 应用或关闭主窗口到系统托盘，会在屏幕右下方、任务栏上方显示独立桌面条。拖动其背景可移动位置，展开按钮恢复主窗口；恢复主窗口或结束通话后隐藏。两种通话条共用原通话、麦克风与计时，不额外建立音频会话。浏览器模式使用应用内通话条。

桌面条的**隐藏通话窗口**按钮可在本次通话中隐藏它，音频和已接受的工作继续进行。状态刷新不会让它重新弹出，开始新通话后重置这一选择。

确认接通后可点击**接管电脑**，音频保持连接。只有准确的当前任务已确认停止、VM 确认人工租约后才开放输入，排队任务同时暂停。**交还 dant** 不会重跑任务，需要继续时可在原通话中重新交代。连接中、停止中或状态未确认时仍禁止开始接管；已有人工租约仍可交还。

附件下载按钮会保留聊天和图片预览。桌面“另存为”默认使用原文件名与扩展名，浏览器模式发起文件下载；取消后保留当前视图。

dant 回复中的本地输出链接会打开对应的已归档附件。明确引用的文件直接读取，无关输出文件超过自动扫描上限时也不影响图片交付。旧链接缺少附件时，点击可把原输出路径下当前文件的快照补到原消息中；这个副本可能比原回复更新。恢复不会重新执行任务；文件已丢失、受限或过大时仍不可用。

同条消息内的附件使用统一间距，紧凑文件卡片把文件名、**查看**和下载按钮放在同一边框内。长文件名保持单行，悬停可查看全名，下方显示类型和大小。图片加载期间会预留空间，失败时显示稳定的错误提示；这项调整改善显示，不改变传输速度。

文本和代码附件提供**查看**及独立下载按钮。点击聊天或对话详情中的文件名，可打开能关闭的纯文本预览。JSON 格式化会保留原始数字值；嵌套过深或格式化后过大时，显示完整原始文本。预览支持最大 1 MiB 的 UTF-8 文本，较大文件仍可下载或使用桌面编辑器打开。HTML、SVG 只显示源码，不执行链接、标记或脚本。

在**通用 → 打开方式**中，可保留 Windows 记事本，或选择已安装且受支持的编辑器程序，例如 VS Code、Notepad++、Sublime Text、Zed 或 Cursor。**0.4.7** 使用应用菜单显示已安装编辑器的图标、名称和当前选中项的勾选标记；**选择其他编辑器…**保留原生程序选择器，已有的自定义编辑器设置也会保留。选择编辑器只保存偏好，不会启动程序。**在编辑器中打开**会打开最大 10 MiB 文本附件的本地副本，不更改聊天附件。应用直接启动指定编辑器，不使用可能执行脚本的文件关联。未改动的缓存副本三天后过期，之前打开并编辑过的副本会保留。

可复用技能使用独立侧栏页面，可通过**导入技能**预览来源，也可点击托管卡片的**下载 ZIP**。详见[凭据与技能](credentials-and-skills.md)。

**0.4.7** 的外部编辑器副本保存在当前用户临时目录的 `dant-text-editor` 中，避免打包版 Windows 编辑器看到不同应用缓存视图时无法打开。已有 AppData 副本保持原样。dant 清理时会保留改动过的副本，但 Windows 可能清理临时文件；需要长期保存的编辑内容请在编辑器中**另存为**。

## Telegram 消息转发

在**设置 → Telegram → 消息转发**中，可选择**仅未读回复（推荐）**或**所有回复**。仅未读模式避免转发已在 dant 中读过的回复；所有回复模式也会转发这些已读回复。dant 与 Telegram 的已读／未读状态保持独立。**合并连续回复**默认开启，将连续文字回复合并为较少的 Telegram 消息，附件单独送达。修改后自动保存，不会更换机器人令牌、修改配对或重启 Telegram 轮询。这些控件需要匹配版本的工作电脑服务。**0.4.7** 会在连接并空闲时自动更新，**设置 → 工作电脑**会显示待更新、更新中、已确认及失败状态。

## Windows 后台运行

点击主窗口的 **X** 会把 dant 收到 Windows 系统托盘。应用、通话和已接受的任务继续运行，关闭窗口不会暂停或取消工作。点击托盘图标或选择**打开 dant** 可恢复原窗口，再次启动 dant 也会恢复已有实例。

托盘显示简短的在线、工作或等待状态及排队数量，点击**任务进度**可直接打开任务面板。托盘文字不包含消息、任务标题、文件名或凭据；断连或缓存中的未结束任务会显示状态待确认，不会被当成完成。

在托盘菜单选择**显示通话窗口**可恢复已隐藏的桌面通话条；没有当前通话时此操作不可用。

要结束应用，请在托盘菜单选择**退出 dant**，应用会执行正常关闭流程。手动安装更新前请使用此操作，应用内更新会自行处理重启。如果系统无法创建托盘图标，关闭主窗口仍会正常退出，避免留下无法访问的隐藏应用。托盘功能不会在 Windows 重启后自动启动 dant。

## 定时任务

左侧栏 Skills 旁的时钟入口打开**定时任务**。可以搜索、筛选即将执行、已暂停和历史条目，创建、编辑、暂停或移除任务。新建采用本机时区，编辑保留任务原有时区，显示在日期时间字段旁；每条记录显示保存的执行时间和时区。创建或编辑只保存安排，不会立即执行任务内容。

**0.4.7** 在**执行一次**之外支持**每天**、**每周**和**自定义 Cron**，并支持**高**、**普通**、**低**优先级。Cron 使用五个字段：分钟、小时、日、月、星期。例如 `0 9 * * 1-5` 表示按保存的时区，每周一至周五 09:00 执行。服务计算下次执行时间；暂停会保留规则，过期的重复任务恢复时推进到未来的下一次。优先级影响等待启动的定时任务排序，不会打断正在执行的任务，也不会改变普通聊天消息在队列中的位置。

重复任务离线错过后，恢复可用时只补跑一次，再推进到未来匹配时间，不会把所有错过的次数一起启动。同一定时任务前一次工作未完成时不会重叠执行，包括暂停、等待你回复或提交结果未确认的情况。使用重复规则和优先级前，需要更新旧工作电脑服务。

工作电脑现在将调度和派发回执保存在 `schedules/schedules.sqlite`，聊天消息仍单独保存。旧 JSON 调度先备份、仅导入一次。派发中断后，恢复可以补回同 ID 的暂停消息，但不会再次发送结果不确定的动作；已保存交接回执也不代表任务完成。移除或修改后的调度不会被旧 JSON 副本复活。

也可以在聊天或通话里直接让 dant 安排工作，共享的 `schedule_list`、`schedule_save`、`schedule_delete` 工具管理同一批记录。dant 需要采用正确时区，并在保存确认后才能声称安排成功。工作电脑不可用、正在通话或被人工接管时，到期任务等待执行通道恢复；关闭窗口收到托盘会保留服务。
